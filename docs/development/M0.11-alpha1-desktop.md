# M0.11 Alpha 1 native desktop verification

M0.11 adds the first runnable native MAIA desktop surface using `eframe` over
the accepted Rust Core, authoritative SQLite adapter and loopback-only local
briefing adapter. It is a presentation adapter, not a new semantic authority.

The Alpha 1 flow accepts one explicitly chosen UTF-8 `.txt` or `.md` file,
creates an immutable MAIA-owned artifact snapshot with a content hash and an
append-only audit record, then builds a bounded M0.10 briefing packet from
those snapshots. It calls only `127.0.0.1:11434` with the qualified local Qwen
model. The returned response must pass the existing citation validation before
it is atomically persisted with its packet, result, provenance and audit event.
The desktop history reloads artifacts and accepted briefings from SQLite after
restart. Citation inspection uses the recorded packet snapshots, and the
surface does not make file paths primary user-facing citations.

This slice exposes no connector, HTTP listener, cloud fallback, Approval,
Decision, Commitment, WorkGraph promotion or execution control. Accepted
briefing results retain `execution_authority=false` structurally and at the
persistence boundary.

Run `tools/Start-MAIA-Alpha1.ps1` for a local developer launch. The approved
dependency record is [M0.11 dependency provenance](M0.11_DEPENDENCY_PROVENANCE.md).
