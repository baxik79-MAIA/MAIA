# M0.1: Rust canonical domain foundation

MAIA 1.2.1 canonical YAML feeds `tools/generate_rust_domain.py`, which writes
`core/domain/src/generated/contracts.rs`. Run the generator after canonical
changes and review the derived diff. Never edit generated declarations manually.
Spec Guard checks drift without invoking Cargo or requiring a Rust toolchain.
The generator uses the existing Python/PyYAML environment and no new packages.

The edition-2024 workspace contains only `maia-domain`, with zero third-party
Rust dependencies. `Cargo.lock` records that dependency-free workspace. Rust 1.85
is the declared minimum; local validation used Rust/Cargo 1.98.1.

Canonical references supply enum order, all four execution FSMs, certainty
coupling, ID declarations, integer widths/minima, and entity/value-object fields.
There is no handwritten duplicate enum or field inventory. Handwritten macros
provide constructors and read-only getters; handwritten validation supplies
string/calendar rules and cross-field invariants. Generated formatting is kept
independent of rustfmt using a module-scoped skip; drift checking verifies it.

Constructors accept every canonical field explicitly (including `Option` and
empty vectors). Fields are inaccessible for mutation outside the crate. Run
construction rejects mismatched certainty; its transition method changes state
and certainty together. Action construction requires connector identity for
nonempty source preconditions. RiskSummary sorts and deduplicates in canonical
risk declaration order. Absent estimates remain different from known zero;
optional strings can preserve an explicitly present empty string where allowed.

IDs validate canonical lowercase UUIDv7 text; they do not generate identities.
Timestamp accepts only `YYYY-MM-DDTHH:MM:SS.sssZ`, with Gregorian leap-year/date
validation and hour/minute/second bounds. Broader RFC3339 parsing and offset
normalization belong to a later boundary adapter. Opaque strings are preserved,
including whitespace; they do not acquire path, URI, or authorization semantics.
Version enforces the canonical numeric range; aggregate compare-and-swap and
monotonic version advancement must be enforced by later orchestration/storage.

FSM methods check structural edges and return explicit errors. They do not
establish authorization, quiescence, source freshness, or reconciliation proof.
Callers must enforce these policies and record audit events before committing
state changes. In particular, a legal Approval transition is not an ApprovalGate
implementation, and constructing historical states does not authorize execution.
Run identities are independently optional and do not select or infer a fallback.

## Local offline validation

Set `CARGO_NET_OFFLINE=true`. Run:

```text
python tools/spec_guard.py
python tools/validate_spec.py
python tools/generate_document_fragments.py --check
python tools/generate_rust_domain.py --check
python -m unittest discover -s tests/spec
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo test --workspace --offline
git diff --check
```

Rust tests cover domain validation, FSM edges and invalid shortcuts, historical
approval preservation, independent optional fields, and certainty changes.
Compile-fail doctests verify ID non-interchangeability and the absence of Action
Paused. Python regressions compare generated edges/coupling against YAML and
exercise enum, ordering, state, field, and requiredness drift without modifying
canonical files.

## Scope and acceptance

This foundation contributes to A007/A009 (canonical drift), A010 and M011
(OS-neutral contracts), A011 (structural pause edges), M014 (historical approval
FSM), and M017 (structural reconciliation edges). It does not claim end-to-end
fulfillment of policy or runtime acceptance criteria. No canonical YAML changed.
No migration is required. Errors omit input values; no I/O or side effects exist.

Deferred: serde/wire adapters, general RFC3339 normalization, UUID generation,
persistence, scheduler, routing, connectors, model providers, ApprovalGate,
concurrency/CAS orchestration, audit storage, MCP runtime, network services and UI.
