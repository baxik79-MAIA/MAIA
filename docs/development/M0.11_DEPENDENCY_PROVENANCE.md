Cargo records the full resolved target-specific dependency closure, source
registry and checksums in the repository `Cargo.lock`. The approved fetch
populated the local Cargo registry cache at
`%USERPROFILE%\\.cargo\\registry\\cache\\index.crates.io-*`; Cargo may build
without re-resolving these selected package archives when that cache and the
locked repository are retained.

The desktop binary has no frontend package manager, WebView, browser runtime,
or separately downloaded Windows runtime asset. Its only model dependency is
the already-qualified MAIA-owned local Ollama/Qwen artifact; its manifest and
model blob were checked present and size-matched before this prefetch. No model
was downloaded or changed.

Commercial review is additive to [ADR-0045](../adr/ADR-0045.md): all direct
desktop crates are dual permissive licensed. Transitive artifacts remain
locked in `Cargo.lock` and must be reviewed from that exact lock before a
redistributed release.
