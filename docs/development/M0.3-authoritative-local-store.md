# M0.3 — Authoritative Runtime State & SQLite Foundation

M0.3 implements the already accepted MAIA 1.4.0 persistence and audit
contracts. `core/store` defines focused OS-neutral repository and transaction
ports; `infra/sqlite` provides the local adapter.

The adapter keeps one writable authority per workspace with an exclusive lock,
foreign-key enforcement and WAL. T1–T5 are immediate transactions that include
their audit append. Immutable plan/action history, Approval bindings, Run
attempt uniqueness, Task/Run CAS versions, exact evidence bindings and the
workspace audit chain are persisted with critical fields in normal columns.

The implementation deliberately excludes connectors, policy providers,
scheduler services, workers, Person/Memory/WorkGraph persistence, search and
all UI layers. SQLite dependencies are confined to `infra/sqlite`; no SQL or
filesystem type crosses `core/store`.
