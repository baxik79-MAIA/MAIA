# Development status

MAIA is early-stage, actively developed software. This public source baseline contains the local intelligence recorder-host integration and committed hypothesis-ledger source. Local snapshot validation is recorded separately; GitHub Actions has not yet run. Production readiness, cross-platform application support, process-tree containment, session-store atomicity and detailed provider-error reporting remain separate engineering work.

Live-provider tests remain opt-in or ignored. Publication does not certify a deployment build. GitHub private vulnerability reporting and repository rules require post-push configuration.
