# Development status

MAIA is early-stage, actively developed software. This public source baseline contains the local intelligence recorder-host integration, the hypothesis ledger, deterministic diagnostic hypothesis generation and qualification, and a read-only advisory application boundary in the local intelligence host. Advisory results carry provenance and uncertainty; they grant no action authority. Local snapshot validation is recorded separately; GitHub Actions has not yet run. Production readiness, cross-platform application support, process-tree containment, session-store atomicity and detailed provider-error reporting remain separate engineering work.

Live-provider tests remain opt-in or ignored. Publication does not certify a deployment build. GitHub private vulnerability reporting and repository rules require post-push configuration.
