# Commercial readiness and third-party rights

MAIA-owned project source and architecture are Apache-2.0. External dependencies
retain their licenses; Cargo.lock identifies the resolved Rust dependency set.
Dependencies, runtime models and binary distributions require their own license,
notice, provenance and security review. No model weights or external runtime is
bundled here. The optional documentation publisher requires python-docx.

Before adopting a component, record an immutable version, source, license,
required notices, security/egress behavior, coupling and cost. Distinguish reuse,
adaptation, research-only and rejection. Research is not incorporation approval.

Public source availability does not authorize paid production or customer-data
processing. Existing G2/G3/G4 and human authority boundaries remain applicable.
