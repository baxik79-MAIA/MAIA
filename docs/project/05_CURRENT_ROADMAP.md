# Current roadmap

See [the public roadmap](../ROADMAP.md) and [development status](../DEVELOPMENT_STATUS.md).
The source includes core policy, orchestration, store, runtime and executor
foundations; experimental desktop and host applications; optional Round Table;
and local intelligence health, diagnostics, hypothesis ledger and recorder.

Round Table remains outside Core (ADR-0046). Capability boundaries and the
DEVELOPMENT_EVOLUTION / DEPLOYMENT_LOCKED split remain required. Future
connectors, scheduler workflows and consequential actions require explicit
contracts and acceptance evidence. Publication is not production approval.

Private run histories and provider qualification telemetry are intentionally
excluded. Reproduce current behavior through the public deterministic tests.
