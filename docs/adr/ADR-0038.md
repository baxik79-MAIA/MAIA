# ADR-0038: Trusted Execution Intelligence and replaceable Microsoft 365 validation wedge

Status: Accepted by Architecture Desk for M0.7

## Decision

MAIA is Trusted Execution Intelligence. Its canonical value chain is Signal ->
Context -> Commitment / Decision / Risk -> Plan -> Action -> Run -> Outcome.
Microsoft 365 Execution Control is the initial validation wedge: it tests the
ability to detect, organize and complete source-linked operational work from
Microsoft 365 communication, meetings and documents.

The wedge is explicitly replaceable and does not define a Core boundary. Core
remains channel-, connector- and model-neutral. Product expansion follows the
principle narrow wedge, broad architecture, global ambition: architecture must
not create a future ceiling, while implementation stays limited to validated
current needs.

## Consequences

No M365 product name, connector or vendor identity becomes required by generic
Task, Plan, Action, Run or Outcome contracts. A later evidence-backed wedge may
replace the initial one without redefining those contracts.
