# ADR-0042: Provider-neutral Round Table vertical slice and Anthropic adapter boundary

Status: Accepted by Architecture Desk for M0.8

## Decision

M0.8 adds a provider-neutral Round Table vertical slice: DecisionRequest,
RoundTableSession, response-isolated Participant invocations, ParticipantResponse,
Disagreement, adjudication and RoundTableDecision. The Core contract is
reasoning-only. A RoundTableDecision never authorizes an Action; A3/A4 remain
independent of RiskClass, ApprovalAssurance and ApprovalGate.

The first external participant is an Anthropic Messages API adapter in
`infra/anthropic`, behind the neutral Participant/ModelProvider boundary.
Claude model selection is local configuration, not a Core enum or fallback.
The adapter reads `ANTHROPIC_API_KEY` only at the local secret/environment
boundary, requires no organization ID, applies a timeout, retries only safe
transient failures, captures request IDs and returned usage, and never falls
back to another provider or model.

## Consequences

The slice is testable with fake participants without network or credentials.
The live Anthropic smoke test is ignored by default and requires explicit local
opt-in plus environment configuration. No other provider adapter is included.
