# ADR-0044: Local-only source-cited evidence briefing

Status: Accepted by Architecture Desk for M0.10

M0.10 creates a durable MAIA-owned `BriefingResult` from selected immutable M0.6 Artifacts through a bounded provider-neutral consultation packet. It is derived advisory content, never an Action, Approval, MemoryClaim, WorkGraph edge, Decision or Commitment.

The concrete adapter is local-only and must reject non-loopback endpoints. Core has a LocalModelProvider port and knows no runtime/model brand. No fallback or external egress is permitted. Packet evidence is explicit and bounded; provider session history is disposable and non-canonical.

Every evidence-backed statement must use a citation supplied in the packet. Unknown or out-of-packet citations fail validation. Result provenance preserves packet/evidence hashes, identities, locality, actual/requested model identity when available, response hash, outcome, latency, usage and no-fallback result. `execution_authority=false` always; ApprovalGate remains independent.

Packet identity is canonical `briefing_packet_v1` hash over semantic request, evidence, citation namespace, instructions/template version, response contract, privacy/egress, assurance and model-routing constraints; transport timestamps, latency and provider-session identifiers are excluded. A raw provider response is untrusted and cannot become a successful result before shape, limits, claim class and citation validation. Successful packet/result/provenance/citation/audit persistence is atomic and immutable; retry count is zero in M0.10.
