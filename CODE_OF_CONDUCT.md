# Code of conduct

Treat contributors and users respectfully. Discuss ideas and evidence, give constructive feedback and make room for different backgrounds and experience levels.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, deliberate disclosure of private information and sustained disruptive behavior are unacceptable in project spaces and when representing the project.

Maintainers may edit or remove harmful content, limit participation or exclude participants in proportion to the conduct. Decisions should respect confidentiality and allow an appeal to an uninvolved maintainer or the repository owner.

The responsible public maintainer is [baxik79-MAIA](https://github.com/baxik79-MAIA). For conduct concerns, request a private contact route without disclosing incident details publicly. Maintainers must establish that route before opening community discussion spaces. Security vulnerabilities follow [SECURITY.md](SECURITY.md). No response deadline is promised.
